**[Constantino IT](https://constantinoit.com)** is my company, specialized in **software development**. We help businesses turn ideas into reliable digital products:

| | Service | What we do |
|:-:|---|---|
| 💻 | **Web Development** | Modern, fast and responsive websites and web apps |
| 📱 | **Mobile Apps** | Native and cross-platform apps for iOS and Android |
| 💡 | **IT Consulting** | Architecture, code reviews and technology strategy |
| ☁️ | **Cloud Solutions** | Deployment, hosting and scalable cloud infrastructure |

> 🌍 The website itself is a multilingual SPA available in **9 languages** (EN, ES, IT, PT, FR, DE, 中文, 日本語, العربية), built with React 19 + Vite and an Angular port — source in [`cit-react`](https://github.com/ademirconstantino/cit-react).
